# Component review

Read repository contracts and the complete diff. Trace client calls through component validators, indexed reads, lease-fenced writes and app authorization. Check default-runtime portability, bounds, fixed errors, packaging, generated bindings and retention. For each defect, report file, line, reachable input, consequence and fix. Distinguish simulator, local runtime and live-provider evidence.
