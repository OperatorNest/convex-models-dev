# 0003: Bounded cheapest scan

`models.listCheapest` reads `by_costBlended` in ascending order when no providers are selected. With `modelsDevProviderIds`, it merges deduplicated `by_modelsDevProviderId_and_costBlended` ranges, at most 64 per query, in ascending blended cost and creation time. All ranges share a 1927-row scan bound, `floor(8 MiB / (4096 + 256))`: normalized model rows are at most 4096 bytes of serialized JSON, 256 bytes cover the stored `contentHash`, `firstSeenAt`, `updatedAt`, `_id` and `_creationTime`, and 8 MiB is half of Convex's 16 MiB per-query read limit. The largest row in the measured live catalog (8773 models) is 1702 bytes, so the 4096-byte model row limit leaves 2.4 times headroom. The bound assumes each scanned row is read once; read-ahead by the Convex index iterator is not measured. It filters capabilities and collapses canonical duplicates during iteration.

The result is `{ models, isComplete }`. `isComplete` is false whenever the scan bound stops a read before the requested matches. Exhausted ranges produce a complete short result; reaching the requested matches produces a complete result. Callers needing exhaustive results use paginated listing.
